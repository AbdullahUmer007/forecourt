Home page template

Search-first hero, no stock photograph, no slider, no motion at all. One action from landing to a filtered stock list; the trust answer sits in the hero band, above any marketing. Shown for a 123-car dealer and a 14-car dealer from identical markup. Scroll inside each frame.

The search card sits directly under the headline, so the first screen is: are you open · what have you got · pick three things · go. The four proof lines close the hero band before any section can start selling.

A wide, badly proportioned logo is boxed at 36px high and never allowed to set the masthead's height; the dealer's name is typeset beside it in Inter, so a bad logo cannot make the page look amateur.
